# BK-023 completion evidence

## Scope

Upgraded the transitive `fast-uri` package used by Ajv from vulnerable `3.1.5` to patched `3.1.7`. The dependency resolution changes only `package-lock.json`, and `test/fast-uri-security.test.mjs` pins the three advisory boundaries through Ajv's configured URI resolver. The slice adds no direct dependency, runtime API, network path, feature, or speculative abstraction.

## Red evidence

Before the update, the lockfile resolved Ajv's `fast-uri` dependency to `3.1.5`, and `npm audit` reported one high-severity vulnerable package covering GHSA-5jgf-p345-68v8, GHSA-f65p-4m7j-42xc, and GHSA-fph4-wmhf-6fwf. The advisories affected versions below `3.1.6`, so the existing resolution could not satisfy BK-023.

The retained advisory test was also run against installed `fast-uri@3.1.5`: all three cases failed. The old resolver silently normalized malformed bracketed IPv6 input to another host, double-decoded an encoded hostname to `localhost`, and retained a raw non-ASCII host when resolving a scheme-relative URI.

## Change

The pinned npm 11.9.0 package manager refreshed the transitive resolution without changing `package.json`:

```text
fast-uri: 3.1.5 -> 3.1.7
changed source files: 0
changed lockfile entries: 1
```

`npm ls fast-uri --all` confirmed that `ajv@8.20.0` resolves `fast-uri@3.1.7` after installation. The retained tests assert that the resolver now reports malformed bracketed IPv6 input, preserves a nested percent-encoded hostname rather than creating a live destination, and canonicalizes a scheme-relative internationalized hostname identically to its explicit-scheme form. Valid IPv6 and ordinary HTTP URI controls still pass.
