# BK-041 selected work-map handoffs

The selected coordinator supplies an exact successful task result. Bookie stores the operation and execution IDs and the manifest and final SHA-256 in the selected Document. The real answer stays with its producer. A subsequent read resolves that same reference before showing the next review action. The human viewer verifies the answer digest and renders the saved text locally.

The work-map regression reproduced a settled task stuck in the blocked state before this change. The new flow exercises declining permission, matching and mismatched settlement events, one canonical write, replay, changed evidence, out-of-scope working roots and opening the saved answer without accepting it. A separate case covers ambiguous output slots, valid operation identifiers with a slash, and rejecting attachment to a changed task revision. Run these with `npm run build && node --test packages/pi-extension/test/work-map.test.mjs`.

This change extends SPEC-003 and ADR-0012. The feature requires a coordinator with the retained-handoff capability. It does not require Principal or JEV.
