Original trial request, result and vault are preserved outside this worktree.

Fix the static error allowlist and retain only exact, non-sensitive failed-status strings in Bookie context. Arbitrary error bodies and details remain filtered; permissions and successful bodies are not restored. Unknown post-write outcomes retain the no-blind-retry warning. No core validator is weakened.

The separate explicit Pi-package helper builds schema-compatible process actor/time/ACT-ULID from actual host session identity and secure default entropy. It does not save or infer Project/path/class/approval. The recipe persists one complete request and reuses it after interruption. See SPEC-003 and ADR-0009's dated clarification.
